# SimpleWeatherApp
This was my first ever Program I wrote for the college board AP CSP test.



Orignal ReadME

This app was created by Alexander Bindas for the
2025 CREATE TASK for AP Computer Science Principles. The app uses the Google Maps API to get the latitude and longitude of an entered location, and then uses the OpenWeather API to get the weather for that location.
The app is built using only Python. The app is designed to be simple and easy to use, with a clean design and for terminal interfaces.
I used some YouTube videos for help and ChatGPT for the ideas and for help the code is completely mine.
Thank you for checking the app out <3
